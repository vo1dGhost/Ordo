# Ordo 品牌命名规范

本文统一项目文档和宣传素材中的名称与文案。产品功能与版本状态见[项目说明](../README.md)，图标与演示资源见[素材说明](../Artwork/README.md)。

## 品牌名称

| 项目 | 写法 | 使用约定 |
| --- | --- | --- |
| 正式英文品牌名 | **Ordo** | 文档正文、应用名称、窗口标题和无障碍文本均使用此拼写。 |
| 中文辅助名候选 | **格序 / 窗序** | 两个备选名称，尚未选定其一；正式产品名称继续使用 Ordo。 |
| 视觉字标 | **ØRDO** | 用于 Logo、海报、宣传封面等视觉展示，文字说明与图片替代文本使用 Ordo。 |

Ordo 来自拉丁语中的“秩序、排列”，与窗口管理的核心理念一致：让每个窗口处于合适的位置。

四个字母简短、利落，适合在菜单栏应用及品牌素材中识别；整体表达保持简洁、专业。名称不局限于矩形吸附，可容纳工作区、自动化规则、多显示器和应用编排等未来方向。这些方向是命名延展空间，不构成功能或发布承诺。

视觉字标使用字母 `Ø`，完整写作 `ØRDO`；Ø / 空集是视觉语言参考。正式拼写仍为 `Ordo`，工程名称、Bundle ID、文件名、下载附件名称及命令沿用既有命名，不因字标而改为特殊字符。

## 产品定位与标语

| 用途 | 英文 | 中文 |
| --- | --- | --- |
| 完整产品定位 | Ordo — Window Manager for Mac | Ordo — Mac 窗口管理与快捷布局 |
| 品牌标语 | Every window, in its place. | 让每个窗口，各得其所。 |

标题和宣传首屏可按受众选择一种语言，项目首页可并列展示两种语言。保留定位中的破折号，以及标语中的逗号和句号。

当前产品的简短介绍：

> Ordo 是一款原生 macOS 菜单栏窗口管理器。按住修饰键并移动鼠标，即可自由移动窗口、调整大小，或选择八向布局并在松键后应用。

## 模块与版本名称建议

以下名称用于未来命名讨论，尚未作为独立模块或版本发布。当前用户文档继续使用“自由移动”“调整大小”“八向排布”等实际功能名称。

| 建议名称 | 对应含义 | 当前使用边界 |
| --- | --- | --- |
| **Ordo Layouts** | 布局预设 | 预留名称；当前固定八向布局仍按实际功能描述。 |
| **Ordo Rules** | 自动排列规则 | 预留名称，不表示已有自动规则功能。 |
| **Ordo Scenes** | 工作区场景 | 预留名称，不表示已有工作区保存或恢复功能。 |
| **Ordo Flow** | 连续窗口操作 | 预留名称；当前移动与缩放尚未使用独立模块品牌。 |
| **Ordo Pro** | 专业版 | 版本名称建议，不表示已有付费版本、定价或升级计划。 |
