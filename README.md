<h1 align="center">Ordo</h1>

<p align="center">按住修饰键，移动鼠标，轻松整理窗口。</p>

<p align="center">macOS 14+ · 原生 Swift · <a href="LICENSE">MIT License</a></p>

## 主要功能

Ordo 是一款原生 macOS 菜单栏窗口管理器，让你直接在窗口上移动、缩放和选择排布，无需寻找标题栏或拖拽窗口边缘。

- **自由移动**：按住组合键，窗口随鼠标移动。
- **调整大小**：固定窗口左上角，用鼠标控制右下角。
- **八向排布**：选择半屏、四角、铺满可见区域或居中布局，松键应用。
- **菜单栏常驻**：随时启用或暂停，不占用 Dock 位置。
- **按习惯设置**：自定义三组组合键、一键恢复默认，并选择是否启用排布动画。

## 开始使用

运行需要 **macOS 14 或更高版本**，以及辅助功能权限。安装包为 Universal 2，包含 Apple Silicon 和 Intel 架构；实际运行验证范围见[验证记录](docs/VALIDATION.md)。

1. 从 [Releases](https://github.com/vo1dGhost/Ordo/releases) 下载 `Ordo-1.0.0-universal.dmg`。
2. 打开 DMG，将 **Ordo** 拖入 **Applications**，然后推出磁盘映像。
3. 从“应用程序”打开 Ordo，按下方步骤授予辅助功能权限。

**当前安装包使用临时签名，尚未经过 Apple 公证。** 如果首次打开被系统阻止，请先确认下载来源，再到“系统设置 → 隐私与安全性”点击“仍要打开”，按系统提示确认。具体提示随系统版本而异，参见 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。

Release 同时提供 `SHA256SUMS.txt` 校验文件。更新版本后可能需要重新授予辅助功能权限，目前不提供 App 内自动更新。

### 首次授权

1. 首次启动 Ordo，主窗口会显示辅助功能权限说明。
2. 点击“授权辅助功能”。
3. 在“系统设置 → 隐私与安全性 → 辅助功能”中启用 Ordo。
4. 返回 Ordo，确认已启用且状态为“正在运行”。

系统授权提示只会在你点击授权入口后触发。

### 日常控制

点击菜单栏中的 Ordo 图标：

| 菜单项 | 作用 |
| --- | --- |
| 启用 | 开启或暂停窗口手势 |
| 打开 | 查看运行状态、管理权限、设置手势与动画 |
| 退出 | 结束 Ordo |

主窗口将运行、权限、手势和动画设置集中在一个可滚动页面中。关闭窗口后，Ordo 仍会在菜单栏运行。

菜单栏图标中央为实心时表示手势正在运行；空心表示手势未运行，可打开主窗口查看原因。

## 手势说明

先将鼠标放到目标窗口的可见区域，再按住组合键并移动鼠标，无需按住鼠标按钮。

| 操作 | 默认组合键 | 使用方式 |
| --- | --- | --- |
| 调整大小 | `⌥⇧`（Option + Shift） | 固定左上角，移动鼠标调整右下角 |
| 窗口排布 | `⌘⌃`（Command + Control） | 向八个方向选择布局，松开组合键应用 |
| 移动窗口 | `⌃⇧`（Control + Shift） | 窗口随鼠标的相对位移移动 |

一次手势始终操作起始时锁定的窗口，途中经过其他窗口不会切换目标。

### 八向布局

按住排布组合键后，以鼠标起点处的八瓣提示为参照移动；对应方向会高亮，移回中心可以取消当前选择。

| 方向 | 布局 |
| --- | --- |
| `←` / `→` | 左半屏 / 右半屏 |
| `↑` | 铺满屏幕可见区域 |
| `↓` | 宽、高各为可见区域的 75%，居中 |
| `↖` / `↗` / `↘` / `↙` | 对应角落的四分之一屏 |

排布会避开菜单栏和 Dock，使用手势开始时所在的屏幕；向上铺满不会进入 macOS 原生全屏。移动和手动缩放允许跨显示器操作。

### 自定义手势

在主窗口的“手势快捷键”中修改组合键。每组至少包含两个修饰键，可选 `⌘`、`⌥`、`⌃`、`⇧`，三组组合不能相同。

点击“重置”会一次恢复三组默认组合，不改变启用状态或排布动画设置。

## 隐私与兼容性

- 不发送网络请求，不包含遥测或行为分析。
- 手势监听只关注修饰键状态和鼠标移动，不读取普通按键内容，也不拦截系统输入。
- 只申请辅助功能权限，不额外申请屏幕录制或输入监控权限。
- 设置保存在本机；运行日志也只写入本地文件。

日志位于 `~/Library/Logs/Ordo/ordo.log`，记录运行状态、权限和手势结果，不包含窗口或 App 身份、位置尺寸、鼠标位置及按键内容。日志会自动轮替，界面不提供日志列表。

macOS 26 使用系统玻璃效果，较早版本保留标准材质回退；界面和动画尊重系统“减少动态效果”与“减少透明度”设置。

目前不支持原生全屏、跨 Space、Split View 或 Stage Manager 的专门适配。固定尺寸窗口或不支持辅助功能控制的应用可能无法调整；窗口置前效果也受目标应用和系统行为影响。不同系统与应用的验证情况见[验证记录](docs/VALIDATION.md)。

## 开发与贡献

<details>
<summary>从源码构建与开发说明</summary>

编译需要包含 macOS 26 SDK 的 Xcode 26 或更高版本，项目使用 Swift 6，未引入第三方依赖。

用 Xcode 打开 [Ordo.xcodeproj](Ordo.xcodeproj)，选择 `Ordo` Scheme 和 `My Mac`。

**签名前提**：当前工程使用维护者固定团队的 `Apple Development` 手动签名，需要匹配团队的有效开发证书及私钥。外部开发者自行构建时，需要先为 App 与测试 target 配置自己的有效开发签名。

现有本机更新脚本还会校验固定团队身份，因此不能直接作为通用安装命令。这里的开发签名也不代表已完成对外分发签名或公证。

发布打包使用独立的 [package-release.sh](scripts/package-release.sh)：从指定 Git 提交构建 Universal 2 副本并生成临时签名 DMG，不需要开发证书，也不修改工程的开发签名。运行 `./scripts/package-release.sh v1.0.0` 可构建对应标签；未提交改动不会进入安装包。
