<h1 align="center">Ordo</h1>

<p align="center">Ordo — Window Manager for Mac<br>Ordo — Mac 窗口管理与快捷布局</p>

<p align="center">Every window, in its place.<br>让每个窗口，各得其所。</p>

<p align="center">macOS 14+ · 原生 Swift · <a href="LICENSE">MIT License</a></p>

当前版本为 **v1.0.1（构建号 2）**，包含跨桌面预览恢复、登录自启、菜单栏图标隐藏、静默启动及固定尺寸三页设置。分发 App 已使用 Developer ID 签名并通过 Apple 公证。

当前源码使用 Bundle ID `com.ghoooooost.Ordo`。与旧标识 `com.ghost7.Ordo` 相比，它是新的应用身份；首次使用需重新配置偏好设置、辅助功能授权和登录自启，程序不会自动迁移旧设置或修改旧授权。

## 主要功能

Ordo 是一款原生 macOS 菜单栏窗口管理器。按住修饰键并移动鼠标，即可直接在窗口上移动、缩放和选择排布，无需寻找标题栏或拖拽窗口边缘。

- **自由移动**：按住组合键，窗口随鼠标移动。
- **调整大小**：固定窗口左上角，用鼠标控制右下角。
- **八向排布**：选择半屏、四角、铺满可见区域或居中布局，松键应用。
- **后台运行**：可选登录时自启、隐藏菜单栏图标和静默启动，不占用 Dock 位置。
- **按习惯设置**：自定义三组组合键，一键恢复默认快捷键，并选择是否启用排布动画；排布触发距离固定为 8 pt。

## 开始使用

运行需要 **macOS 14 或更高版本**，以及辅助功能权限。安装包为 Universal 2，包含 Apple Silicon 和 Intel 架构；实际运行验证范围见[验证记录](docs/VALIDATION.md)。

1. 从 [Releases](https://github.com/vo1dGhost/Ordo/releases) 下载 `Ordo-1.0.1-universal.dmg`。
2. 打开 DMG，将 **Ordo** 拖入 **Applications**，然后推出磁盘映像。
3. 从“应用程序”打开 Ordo，按下方步骤授予辅助功能权限。

**v1.0.1 的 App 使用 Developer ID 签名，已通过 Apple 公证并装订票据。** DMG 容器本身未另行签名或公证；映像内 App 已通过严格验签、公证票据及 Gatekeeper 检查。首次打开仍可能显示 macOS 的互联网下载确认提示，请核对来源。历史 v1.0.0 使用临时签名、未公证，不能套用本版本的验证结果。

Release 同时提供 `SHA256SUMS.txt` 校验文件。更新版本后可能需要重新授予辅助功能权限，目前不提供 App 内自动更新。

### 首次授权

1. 首次启动 Ordo，未授权时主窗口会进入“功能”页。
2. 点击辅助功能一行的“授权”。
3. 在“系统设置 → 隐私与安全性 → 辅助功能”中启用 Ordo。
4. 返回 Ordo，确认“启用窗口管理”开关已开启。

系统授权提示只会在你点击授权入口后触发。

### 日常控制

点击菜单栏中的 Ordo 图标：

| 菜单项 | 作用 |
| --- | --- |
| 打开 | 查看运行状态、管理权限、设置手势与动画 |
| 退出 | 结束 Ordo |

菜单仅保留“打开”和“退出”，左侧分别显示窗口和电源图标，不显示快捷键。开启或暂停窗口手势请使用主窗口中的“启用窗口管理”。

主窗口分为“基础 / 功能 / 关于”三页，顶部采用与 macOS 日历相近的标准高度，居中的纯文字胶囊与窗口控制按钮同排、垂直居中对齐，不单独显示“Ordo”标题行。顶部与内容区共用底色，不显示横向分隔线；各项设置以圆角分组卡片呈现。内容区固定为 **560 × 476 pt**，顶部工具栏另由系统布局。每页完整显示，无需滚动或调整窗口大小。关闭窗口后，Ordo 继续在后台运行。

“基础”页管理开机自启、图标显示与静默启动；“功能”页依次管理启用窗口管理、排布动画、权限和快捷键；“关于”页显示当前 App 图标、版本与项目地址。首次展示时，未授权进入“功能”，已授权进入“基础”；同一次运行中重开保留当前分页。

在“基础”页关闭“显示菜单栏图标”即可隐藏图标，手势功能不受影响。之后可通过 Finder 或 Spotlight 再次打开 Ordo 来显示主窗口，图标仍保持隐藏；在主窗口中重新开启显示即可恢复图标。

“开机自启”默认不自动开启。开启后，Ordo 会在当前用户登录时于后台启动，不弹出主窗口；是否启动以系统登录项状态为准。系统未找到当前 App 的登录项时，仅显示关闭的开关，不另外提示。如果系统要求批准，点击“打开登录项设置”完成设置。

“静默启动”默认关闭。开启后，手动启动尚未运行的 Ordo 不显示主窗口；首次使用仍会显示主窗口。无论是否开启，运行中再次通过 Finder、Spotlight 或菜单“打开”都会显示同一个主窗口，不自动恢复已隐藏的菜单栏图标。登录／服务后台启动始终不弹窗。

菜单栏图标中央为实心时表示手势正在运行；空心表示手势未运行，可打开主窗口查看原因。

## 手势说明

先将鼠标放到目标窗口的可见区域，再按住组合键并移动鼠标，无需按住鼠标按钮。

| 操作 | 默认组合键 | 使用方式 |
| --- | --- | --- |
| 调整大小 | `⌥⇧`（Option + Shift） | 固定左上角，移动鼠标调整右下角 |
| 窗口排布 | `⌘⌃`（Command + Control） | 向八个方向选择布局，松开组合键应用 |
| 移动窗口 | `⌃⇧`（Control + Shift） | 窗口随鼠标的相对位移移动 |

一次手势始终操作起始时锁定的窗口，途中经过其他窗口不会切换目标。

鼠标越过 4 pt 启动距离后，追加修饰键或移回起点都不会切换手势；只有在死区内才允许切换到包含原组合的较长组合键。识别窗口较慢时，完整松键后开始的新一轮手势会取代尚未完成识别的旧手势。

切换 macOS 桌面会取消当前手势并清除预览；松开组合键后，可以在新桌面重新操作。

系统临时停用并恢复输入监听时，也会取消旧手势；松开全部修饰键后即可重新操作。

当前开发版将鼠标位置更新与排布动画的目标频率提高到 **120 Hz**，排布动画仍为 200 ms。实际流畅度取决于鼠标、显示器、系统调度和目标应用的响应速度，不保证所有窗口都能达到 120 fps。

连续移动与缩放现使用独立输入线程，并减少重复窗口查询。目标应用响应慢时，主线程恢复后先处理已到达的输入，再直接更新到最新位置，避免逐个补写旧尺寸造成持续落后；不同应用上的实际改善仍以实机操作为准。

### 八向布局

按住排布组合键后，以鼠标起点处的八瓣提示为参照移动；圆环采用无色 Liquid Glass（较早系统保留中性材质回退），通过亮度与边缘强调选中方向，不添加彩色染色或人工渐变。移回中心可以取消当前选择。

| 方向 | 布局 |
| --- | --- |
| `←` / `→` | 左半屏 / 右半屏 |
| `↑` | 铺满屏幕可见区域 |
| `↓` | 宽、高各为可见区域的 75%，居中 |
| `↖` / `↗` / `↘` / `↙` | 对应角落的四分之一屏 |

排布会避开菜单栏和 Dock，使用手势开始时所在的屏幕；向上铺满不会进入 macOS 原生全屏。移动和手动缩放允许跨显示器操作。

### 自定义手势

在主窗口的“功能”页修改组合键。每组至少包含两个修饰键，可选 `⌘`、`⌥`、`⌃`、`⇧`，三组组合不能相同。

八个方向的排布触发距离统一固定为 **8 pt（逻辑点）**，不提供调节入口。鼠标移动超过 8 pt 后选中布局，回到 **16/3 pt（约 5.33 pt）** 以内清除选择。旧版保存的自定义距离停止生效，原值保留供回退旧版使用。

“功能”页右下角的红色“重置快捷键”会立即恢复三组默认组合；有变化时取消进行中的手势并丢弃旧输入。此操作不改变启用状态、排布动画、开机自启、图标显示、静默启动或辅助功能授权。

## 隐私与兼容性

- 不发送网络请求，不包含遥测或行为分析。
- 手势监听只关注修饰键状态和鼠标移动，不读取普通按键内容，也不拦截系统输入。
- 只申请辅助功能权限，不额外申请屏幕录制或输入监控权限。
- 设置保存在本机；运行日志也只写入本地文件。

日志位于 `~/Library/Logs/Ordo/ordo.log`，记录运行状态、权限和手势结果，不包含窗口或 App 身份、位置尺寸、鼠标位置及按键内容。日志会自动轮替，界面不提供日志列表。

macOS 26 使用系统 Liquid Glass：分页胶囊、快捷键键帽和操作按钮采用玻璃材质，设置卡片与窗口圆角同心；较早版本保留标准控件与材质回退；界面和动画尊重系统“减少动态效果”与“减少透明度”设置。键帽按键盘位置排列为 ⇧ ⌃ ⌥ ⌘。每项功能当前所选的快捷键键帽以蓝色突出，未选键保持中性样式，组合仍至少保留两个修饰键。在功能页且窗口获得焦点时，按住修饰键会使三项中的对应键帽临时变绿，松开后恢复；离开该页或窗口失焦会清除反馈，不更改快捷键组合，也不额外申请权限。辅助功能已授权时整行隐藏；未授权或权限撤销后恢复整行及“重新检查”和“授权”按钮。

目前不支持原生全屏、跨 Space、Split View 或 Stage Manager 的专门适配。固定尺寸窗口或不支持辅助功能控制的应用可能无法调整；窗口置前效果也受目标应用和系统行为影响。不同系统与应用的验证情况见[验证记录](docs/VALIDATION.md)。

## 品牌与命名

Ordo 来自拉丁语中的“秩序、排列”，表达让每个窗口处于合适位置的理念。

正式品牌名为 **Ordo**，视觉字标为 **ØRDO**。中文辅助名候选为 **格序 / 窗序**，尚未选定其一；产品名称统一使用 Ordo。完整写法、宣传文案与未来模块的名称建议见[品牌命名规范](docs/BRANDING.md)。

编译需要包含 macOS 26 SDK 的 Xcode 26 或更高版本，项目使用 Swift 6，未引入第三方依赖。

排查卡顿时，可在 Instruments 的 Points of Interest 中查看 `com.ghoooooost.Ordo` 的 `AX validation`、`AX position write`、`AX size write` 区间，分别定位窗口校验、位置写入与尺寸写入的耗时。这些标记不包含窗口身份、位置尺寸或输入内容；120 Hz 的每次更新预算约为 8.33 ms，区间耗时不能直接等同于目标窗口的显示帧率。
